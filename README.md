# AP Mortality Benchmark

Research-only retrospective secondary analysis of mortality prediction in critically ill patients with acute pancreatitis. Not a validated clinical decision tool.

This repository is being prepared for computational reproducibility. The patient-level source workbook is not redistributed. Obtain the publisher's S1 Data (https://doi.org/10.1371/journal.pone.0323330.s001) subject to applicable data-use conditions.

The analysis compares predictor groups, model families and internal validation strategies. External validation and individual predictor timestamps are unavailable.

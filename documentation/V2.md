# AP Mortality Benchmark V2

Research-only, retrospective secondary analysis of acute pancreatitis patients admitted to ICU. This is not a validated clinical decision tool.

## Quick start (Windows PowerShell)

Extract the ZIP, open PowerShell in the extracted `AP_Mortality_Benchmark` directory, and run (Python 3.11–3.13; tested on 3.13.5):

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_all.py --smoke --out smoke_test
.\.venv\Scripts\python.exe run_all.py --bootstrap 100 --jobs 1 --out pilot
.\.venv\Scripts\python.exe run_all.py --bootstrap 1000 --jobs 1 --out final_run
```

If 3.11 is not installed, use `py -3.12` or `py -3.13`. No activation required. `--jobs 1` is the conservative tested mode. Multiple processes are optional, and should be tested locally first. On Linux/macOS use `python3 -m venv .venv` then `.venv/bin/python`. For a different copy of the spreadsheet use `--data path/to/file.xlsx`. The output directory is overwritten for files with the same names. Use separate directories for smoke/pilot/final. 1000 resamples can be computationally intensive; no runtime guarantee. The smoke flag runs **one bootstrap resample**, only to check the workflow, and must not be used for publication estimates. No upload to GitHub is performed.

## Source and limitations

Yang X, Zhang M, Lv L, Chen X, Li Z. Total bilirubin-to-albumin ratio and short- and long-term all-cause mortality in acute pancreatitis: Evidence from the MIMIC-IV database. PLOS ONE 2025;20:e0323330. https://doi.org/10.1371/journal.pone.0323330. S1 Data: https://doi.org/10.1371/journal.pone.0323330.s001. The local workbook is the copy supplied by the user. The source reports 5,894 AP cases, 1,276 ICU admissions, 477 retained after exclusion of noninitial ICU admissions, ICU stays shorter than 24h, or unavailable early bilirubin/albumin. Individual exclusion counts cannot be recovered from this spreadsheet. The source describes first-24-hour ICU parameter averages and random-forest imputation for variables with <20% missingness; the supplied file has no missing cells. The original missingness masks, imputation procedure and individual measurement times are not available. Consequently the present validation is conditional on the released, potentially globally imputed data; it cannot establish absence of upstream leakage. Timing of diagnosis flags is uncertain. ICU stay >=24h does not independently establish outcome timing for every record; ICU admission+24h is the intended landmark, not a verified prediction timestamp. Do not generalize to non-ICU AP, admission-time triage, or external cohorts. Data use and redistribution permissions must be independently verified; do not publish the workbook or patient-level predictions. No independent external validation is performed.

## Analysis plan (defined after examining the released dataset; exploratory)

- Primary model: F3 ridge logistic regression, with 31 raw variables (including categorical fields). F1 demographics (3), F2 demographics + vitals + labs (29), F3 F2 + SOFA/GCS (31), F4 F3 + 12 timing-uncertain diagnosis flags (43). F4 is sensitivity-only and cannot establish causal leakage. Race is included as recorded, not as a biological causal variable; fairness and transportability are untested. A future sensitivity analysis excluding race is advisable. SOFA, age/BUN/SOFA and continuous TBAR are clinical comparators; the outcome-selected TBAR1 threshold is excluded. BISAP cannot be fully reconstructed from these fields.
- F3 models: ridge, LASSO, logistic (unpenalized; possible separation), random forest, histogram gradient boosting. F1/F2/F4 use ridge; SOFA and TBAR use logistic; Simple uses ridge. Hyperparameter grids are deliberately small. All tuning uses negative log loss, 5-fold stratified grouped CV. Patient IDs are grouping keys only, never predictors. Categorical reference levels are alphabetical first categories; binary diagnosis indicators are unscaled. Numerical median imputation and z-scaling, categorical mode imputation and one-hot encoding are fitted within each training fold. The released file is already complete, so this does not reverse upstream imputation.
- Bootstrap: sample patients with replacement, repeat preprocessing, tuning and fitting in each resample; evaluate on resample and original cohort, calculate apparent minus mean(train minus test). This convention applies also to loss metrics. Duplicate patient IDs stay in the same inner fold. Undefined calibration slopes (constant predictions) are recorded as missing, with valid counts. Calibration intercept is offset-based calibration-in-the-large, slope uses a near-unpenalized logistic recalibration. AP is average precision, not trapezoidal PR-AUC. No confidence intervals for optimism-corrected metrics are claimed; raw resampling performance is not a valid confidence interval for corrected estimates. A proper outer/nested bootstrap or independent cohort is needed for inferential intervals.
- Separately, nested 5-fold out-of-fold predictions generate ROC, PR, 5-quantile calibration plots and exploratory DCA over 0.05–0.30 (not clinically established cutoffs). Pooled cross-fitted performance may differ from bootstrap-corrected estimates. Curves are not labelled as bootstrap-corrected. No causal or clinical impact claims. Sample size is limited (70 events), no formal prospective sample size calculation; treat results as exploratory. No model-selection winner is presumed.

## Outputs

`results/data_audit.csv` (all 72 fields and roles); `cohort.json` (data hash and counts); `baseline.csv` (descriptive statistics); `performance.csv` (apparent, corrected and nested OOF, valid replicates); `bootstrap_metrics.csv` (per-resample train/test and tuning); `decision_curve.csv` (apparent, corrected, OOF net benefit); `coefficients.csv` and `primary_scaling.csv` (full-data model coefficients and scaling); `hyperparameters.csv`; `run_metadata.json`; `performance_corrected.tex` (LaTeX table using booktabs). `figures/` includes AUROC comparison, ROC, PR, calibration, DCA in PDF and 300dpi PNG. Patient-level predictions and data are not exported in results. Smoke outputs, if supplied, are labelled with metadata and not for publication.

## Included pilot run

`pilot_20/` contains the completed 20-resample run with 4 workers and all 11 model-feature configurations, plus nested five-fold validation. It is a pilot only, not a publication-grade 1000-resample run. `smoke_test/` is a one-resample workflow test. Four unit tests passed. The pilot highlights a large discrepancy between conventional bootstrap correction and nested CV for highly adaptive tree models: both estimates should be reported, with caution about overlap of the bootstrap training and original evaluation cohorts. Do not treat either as external validation. To export descriptive matched point differences by RQ, run `python compare_results.py final_run`; this produces `results/paired_point_differences.csv` without inferential claims. The included data copy is for the user's local research only; omit it from any public release until permissions are confirmed.

# AP Mortality Benchmark V3 — supplementary analyses

Copy only the new files into the existing V2 project (next to analysis_pipeline.py). Do not replace final_run. No patient data are distributed in this patch. Existing V2 Python 3.13 / pinned dependencies are reused.

## Aoraki

```bash
cd ~/AP_Mortality_Benchmark
mkdir -p logs
sbatch --cpus-per-task=2 --time=01:00:00 --export=ALL,SMOKE=1 run_v3.slurm
```
Check `sacct -j JOBID --format=JobID,State,Elapsed,ExitCode`, and check that the stdout ends in `V3 DONE`. Then submit `sbatch run_v3.slurm`. Do not run these computations on the login node. Monitor `tail -f logs/AP_V3_JOBID.err` (replace JOBID). When completed, archive `tar -czf AP_v3_results.tar.gz v3_final/results v3_final/figures v3_final/metadata.json final_run/results logs`.

If interrupted, submit the same script again only after the original job ends. Atomic per-iteration checkpoints are reused if the dataset, code, settings, dependency versions recorded in metadata and V2 performance input are unchanged. Never run two jobs simultaneously writing the same output directory. For a changed configuration use a new output directory. Smoke runs use 2 iterations each and are not publication results.

## Methods and estimands

* 30 repeated nested CV runs (5 outer folds, 5 inner folds for models with tuning). Identical splits for all 12 configurations including F3 without Race. All preprocessing and tuning occur inside training. Repeat 0 uses the V2 seeds; the script checks agreement with the V2 metrics to tolerance. Means and 2.5/97.5 percentiles describe split variability, not confidence intervals. The comparisons are A minus B (higher AUROC/AP, lower Brier/log loss are better).
* 500 ordinary patient-level bootstrap resamples, each repeating the entire nested CV algorithm with a fixed split seed. Duplicate IDs are kept together in both inner and outer folds; bootstrap multiplicities are retained. Percentile ranges for metrics and paired differences are exploratory sampling-uncertainty intervals for the single nested CV statistic, not for the 30-repeat mean or an externally validated full-data model. Resampling can reduce the number of distinct training patients, bias intervals, and affect coverage. Do not interpret exclusion of zero as a confirmatory significance test. No p-values or multiplicity adjustment are performed; all comparisons are exploratory. No ordinary tests treating folds, repeats or resamples as independent.
* 1,000 OOB refits for the five F3 model families using V2 bootstrap seeds. Evaluate strictly on patients absent from the training resample. Mean OOB AUROC is the unweighted mean of within-resample AUROCs; OOB training includes about 63.2% distinct original patients, so it is not the same estimand as full-cohort model performance. No OOB ROC curve is inferred from average AUROC.
* Exploratory .632+ adaptation for Brier loss only: apparent loss A, pooled OOB prediction loss O (weighted by each resample's OOB size), no-information loss G from independent pairing of original outcomes and full-model predicted probabilities. R=clip((O-A)/(G-A),0,1), w=.632/(1-.368R), estimate=(1-w)A+wO. Undefined if G<=A. Not a canonical AUROC correction; no .632+ AUROC is claimed. This adaptation and choice of loss are explicitly exploratory.
* F3 without Race tests predictor inclusion sensitivity, not fairness or equal performance across demographic groups.
* All analyses remain conditional on the released imputed spreadsheet; missing original timestamps, upstream imputation details and independent validation cannot be remedied here. This is a post-V2 exploratory analysis, not a preregistered confirmatory study.
